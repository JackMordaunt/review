# branding

The platform badges beside the install commands in the README, each in a
light and a dark version. They are static.

The Tux and Apple glyphs are from [Simple Icons](https://simpleicons.org)
(CC0). The Windows badge uses a generic four-pane glyph, not the Windows
logo. Labels are JetBrains Mono Bold, named rather than embedded, so a
renderer without it falls back to its own monospace.
